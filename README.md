# 🧪 Rick and Morty Clean Swift App

A test assignment for the iOS Developer position.

## 📋 Overview

This application consists of two modules:

- 📄 **Character List** — displays characters from the Rick and Morty API
- 📃 **Character Detail** — shows name and image of the selected character

Built using **MVVM** architecture and supports **offline mode**.

---

## 🛠 Tech Stack

- Swift
- UIKit
- MVVM *(Clean Swift planned)*
- CoreData *(planned)*
- URLSession
- URLCache
- No Storyboards — 100% programmatic UI
- Supports iPhone & iPad, portrait and landscape
- Offline Mode
- Time Spent ~3-5h
